# Evidências de Testes

## 1. Objetivo

Este documento reúne os procedimentos e as evidências de testes realizados no site **Além dos Limites**, com o objetivo de verificar seu funcionamento, acessibilidade, responsividade e conformidade com padrões de desenvolvimento web.

Os testes previstos seguem os requisitos da Atividade 06 e contemplam validação HTML, navegação por teclado, contraste de cores e visualização em dispositivos móveis.

## 2. Validação W3C

**Objetivo:** verificar se o código HTML das páginas segue os padrões estabelecidos pelo W3C.

**Ferramenta utilizada:** [W3C Markup Validation Service](https://validator.w3.org/)

**Procedimento:**
1. Acessar o validador W3C.
2. Informar o endereço de cada página publicada ou enviar os arquivos HTML.
3. Executar a validação.
4. Verificar se existem erros ou avisos.
5. Corrigir os problemas identificados e realizar uma nova validação.

**Resultado:** Executado

Ver a pasta

## 3. Teste de responsividade

**Objetivo:** verificar se o site se adapta adequadamente a diferentes tamanhos de tela, mantendo a organização e a legibilidade do conteúdo.

**Procedimento:**
1. Abrir o site no navegador.
2. Utilizar as ferramentas de desenvolvedor (`F12`).
3. Ativar o modo de visualização responsiva.
4. Testar diferentes dimensões de tela, incluindo celular, tablet e computador.
5. Verificar menus, imagens, textos, tabelas e demais elementos.
6. Observar se existem elementos cortados, sobrepostos ou com rolagem horizontal desnecessária.
